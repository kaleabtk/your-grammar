# YourGrammer ✍️🤖

**Your Grammer** is a web-based grammar and spelling checking tool that helps users improve their writing.  
Users can enter or paste a sentence into a text box, click the **Check** button, and instantly receive **corrected text** along with **suggestions**.

The system is built using **Next.js** and powered by an **AI** to provide accurate and intelligent language feedback.

---

## ✨ Features

- 📝 Grammar checking
- 🔤 Spelling correction
- 💡 Writing suggestions and improvements
- 📋 Paste or type text easily
- ⚡ Fast and responsive interface
- 🤖 AI-powered text analysis

---

## 🚀 How It Works

1. User enters or pastes a sentence into the text input box.
2. User clicks the **Check** button.
3. The system sends the text to an AI API.
4. The AI analyzes the sentence.
5. Corrected text and suggestions are returned and displayed to the user.

---

## 🛠️ Built With

- **Next.js** – React framework for web applications
- **JavaScript**
- **AI API** – For grammar and spelling analysis
- **HTML & Tailwindcss** – User interface design
